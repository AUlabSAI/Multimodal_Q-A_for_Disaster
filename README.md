# Overview
Here is a lightweight, multimodal Retrieval-Augmented Generation (RAG) pipeline designed for the extraction, cross-modal alignment, and querying of disaster-related government protocols and field imagery in Assam.

Powered by Small Language Models (SLMs) like Gemma-3-4B-IT, this system is specifically optimized for offline deployment on resource-constrained edge devices (e.g., 8GB–16GB VRAM field workstations) utilized by emergency response teams. For comparison of the performance of Gemma-3-4B-IT for this specified task, four SLMs viz. InternVL3.5-8B, Phi-3-Vision, Qwen2-VL-2B, and ViLT+RoBERTa were used. The Gemma-3-4B-IT model outperformed the other models for answer generation, as well as in latency.
