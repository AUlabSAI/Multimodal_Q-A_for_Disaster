# Overview
Here is a lightweight, multimodal Retrieval-Augmented Generation (RAG) pipeline designed for the extraction, cross-modal alignment, and querying of disaster-related government protocols and field imagery in Assam.

Powered by Small Language Models (SLMs) like Gemma-3-4B-IT, this system is specifically optimized for offline deployment on resource-constrained edge devices (e.g., 8GB–16GB VRAM field workstations) utilized by emergency response teams. For comparison of the performance of Gemma-3-4B-IT for this specified task, four SLMs viz. InternVL3.5-8B, Phi-3-Vision, Qwen2-VL-2B, and ViLT+RoBERTa were used. The Gemma-3-4B-IT model outperformed the other models for answer generation, as well as in latency.

# Data description in Repository

**1. Data Processing & Knowledge Extraction:**
Knowledge_block_extracter.ipynb
Implements the foundational extraction pipeline. This notebook is responsible for parsing the source disaster management documents (PDFs), performing layout-aware chunking, and extracting discrete visual artifacts to build the multimodal knowledge base.

**2. Model Inference & RAG Pipelines:**
These notebooks contain the end-to-end Retrieval-Augmented Generation (RAG) implementation, including vector indexing (ChromaDB), model loading (with optimized VRAM quantization), and the generation loops for each respective architecture:

  * **Gemma_3_4B_IT.ipynb**: Implementation pipeline for Gemma-3-4B-IT (Proposed optimal edge architecture).
  * **InternVL3_5_8B.ipynb**: Implementation pipeline for InternVL-3.5-8B.
  * **Phi_3_Vision.ipynb**: Implementation pipeline for Phi-3-Vision.
  * **Qwen2_Vl_2B.ipynb**: Implementation pipeline for Qwen2-VL-2B.
  * **ViLT+RoBERTa.ipynb**: Implementation pipeline for the baseline ViLT + RoBERTa architecture.

**3. Evaluation Suite & Results:**

* **Multi_modal_disaster_Q&A_evaluation.ipynb:**
The core evaluation script. This notebook computes quantitative performance metrics (e.g., BLEU, ROUGE-L, BERTScore, and Semantic Answer Similarity) by benchmarking the generated responses against the expert-curated ground truth.

* **Evaluation dataset after text preprocessing.xlsx:**
The standardized results matrix. This dataset contains the preprocessed outputs generated by all five models alongside the curated ground truth answers used for metric computation.
